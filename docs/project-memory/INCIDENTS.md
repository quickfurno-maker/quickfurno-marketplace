# QuickFurno Incident Memory

Last reviewed: 2026-09-14

Add incidents only after facts and resolution are reviewed. A chat mention alone is not an incident record.

## Incident template

```text
## QF-INC-NNN — Title
Detected:
Resolved:
Environment:
Severity:
Status:
Symptoms:
Root cause:
Impact:
Resolution:
Prevention / guards added:
Evidence:
Related commits / PRs:
Superseded assumptions:
```

When an incident changes a durable rule, update `DECISIONS.md` or `BUSINESS_RULES.md` as well.
